Fixes six issues found by review of this branch: `helm upgrade --reuse-values` no longer crashes when the release predates `externalBroker`, an apostrophe in an external broker URL no longer corrupts the rendered Secret, the local test values no longer hardcode the Dragonfly Service, a null `serviceAccount.create` override no longer leaves a Deployment referencing a ServiceAccount that was never created, the Helm end-to-end job no longer aborts when its diagnostic commands run before the pmp pod is up, and the `bump-my-version` README rule is now scoped to the chart install command so it cannot rewrite other versioned commands.
