Sets `REF_DIAGNOSTIC_PROVIDERS` on every component from the workers under `providers`,
so the solve only considers providers the release actually deploys.
Previously the REF discovered every provider entry point installed in the image,
and one with no worker queued executions that never ran.

Set `pinDiagnosticProviders: false` to restore the old discovery,
or give a provider an `entryPoint` when its package is not named `climate_ref_<provider>`.
